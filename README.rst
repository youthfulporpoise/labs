System Software and Microprocessors Lab
=======================================

The lab programs for CSL331 and others relevant.  The following are the lab
cycles and their corresponding programs.

#. Cycle 1: OS Concepts

   #. CPU scheduling algorithms: FCFS; SJF; RR; Priority
   #. Banker’s algorithm
   #. Disk scheduling algorithms: FCFS; SCAN; FSCAN
   #. Page replacement algorithms: FIFO; LRU; LFU
   #. File allocation: Sequential; Indexed; Linked
